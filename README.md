# קוראים חכמים 📚👾

קורס דיגיטלי ממושחק לשיפור הבנת הנקרא בעברית — לתלמידי כיתות ג׳ ו־ד׳.

עולם משחק שלם בהשראת Reading Eggs ו־Matific: מפת מסע עם תחנות, דמות שצוברת מטבעות,
חנות שדרוגים, ספר מסע, ומשחקוני ארקייד עם מפלצות מצחיקות שמלמדים משפחות מילים והבנת הנקרא.

## ▶️ איך משחקים

פותחים את `app/index.html` בדפדפן. זהו — אין התקנות, אין שרת.
ההתקדמות נשמרת אוטומטית בדפדפן (localStorage).

## 🎓 העקרונות הפדגוגיים

- **חשיפה הדרגתית לטקסט** — משפט אחד ← קטע קצר ← פסקה שלמה. אף פעם לא מתחילים מטקסט ארוך
- **מנוע קבוע, דלק מתחלף** — אותם משחקונים בכל יחידה, נושא וטקסטים מתחלפים, רמת קושי עולה
- **תנועה ומשחק** — מילים תופסים באוויר, מפלצות מאכילים, לא רק שאלות רב ברירה
- **שגיאה היא חלק מהמשחק** — 3 פסילות מחזירות את הפעילות להתחלה, בלי עונש אמיתי
- **דמות מלווה** — אלף הינשוף 🦉 מדריך בכל שלב

הסילבוס המלא (9 יחידות): [syllabus.md](syllabus.md)

## 📁 מבנה הפרויקט

```
app/
  index.html        נקודת הכניסה — כל העולם
  css/style.css     כל העיצוב
  js/data.js        תוכן היחידות, מפלצות, חנות, מפה
  js/engine.js      מנוע המשחקונים (8 סוגי פעילות)
  js/world.js       מפה, דמות, חנות, ספר מסע
  js/state.js       שמירת התקדמות (localStorage)
  js/sound.js       אפקטים קוליים (WebAudio, בלי קבצים)
  assets/img/       תמונות AI (בהפקה — יש fallback מצויר לכל תמונה)
CLAUDE.md           הנחיות פיתוח והחלטות עיצוב
syllabus.md         סילבוס 9 היחידות
image-prompts.md    פרומפטים ליצירת תמונות ה-AI
```

## 🚧 סטטוס

- ✅ עולם המשחק המלא: מפה, דמות, מטבעות, חנות, ספר מסע
- ✅ יחידה 1 "בונים עולמות" — 12 שלבים, שלושה משחקוני מפלצות
- 🔄 יחידות 2–8 — בפיתוח
- 🔄 תמונות AI — הפרומפטים מוכנים, בינתיים placeholders מצוירים
